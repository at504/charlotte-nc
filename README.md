## How to Host (No WordPress / PHP Required!)
1. **cPanel / Apache / Shared Hosting:**
   - Unzip this archive and upload all files directly into your `public_html` directory.
2. **Netlify:**
   - Drag and drop this unzipped folder into Netlify Drop (https://app.netlify.com/drop).
3. **Vercel / Cloudflare Pages / GitHub Pages:**
   - Push to a GitHub repository or deploy via CLI (`npx vercel`).
